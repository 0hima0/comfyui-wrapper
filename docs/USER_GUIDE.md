<a id="generation"></a>
## 画像生成

1. 「画像生成」で指示または追加Positiveを入力し、生成モデル・必要なLoRA・生成条件を選ぶ。
2. 参考画像の有無に応じて「指示から生成」または「画像を解析して生成」を実行する。
3. 右上で進捗を確認し、完了後に「結果を見る」からPNG・JSON・ZIPを保存する。

| 入力 | 用途・制約 |
|---|---|
| 指示 / 追加Positive・Negative | 指示はOllamaで解析、追加Promptは最終Promptへ統合。各8000文字 |
| 参考画像 | PNG / JPEG / WebP、最大4枚・合計2400万画素、送信全体25MiB以内 |
| LoRA | 最大3個、MODEL / CLIP強度・トリガー・適用先を指定。トリガー各2000文字 |
| レーティング | 手動指定、またはWDによる先頭参考画像の自動判定 |
| 人物維持 | 1枚1人の画像を2〜4枚、追加順に左から右へ配置。[依存導入](ADDITIONAL_SETUP.md#people) が必要 |

- 参考画像は解析用です。通常の生成はimg2imgではありません。画像なしでもOllamaは必要で、WD・自動レーティング・人物維持は使いません。
- モデル変更はプロファイル既定値の適用と非対応LoRAの解除を伴います。推奨設定の適用は別操作です。
- 人物LoRAのトリガーは人物別Prompt、全体用LoRAは全体Promptへ反映します。
- 通常生成と連続生成は同時実行できません。設定間はサイドバーで移動し、補足はⓘで確認します。

<details>
<summary>生成パラメーターの受付範囲</summary>

モデル推奨値とは別です。同じSeedでもモデル・ノード・実行環境を変えると完全再現は保証されません。

| 項目 | 範囲・意味 |
|---|---|
| 幅・高さ | 各256〜2048、64の倍数 |
| Seed | 0〜9007199254740991。空欄は自動決定・保存 |
| Steps / CFG | 1〜10000 / 0〜100 |
| Sampler / Scheduler | ComfyUIの候補から選択 |
| Denoise | 0〜1、初期値1 |
| CLIP skip | 0〜24、0は変更なし。Anima非対応 |
| LoRA強度 | MODEL / CLIPともに-2〜2 |
| WDしきい値 | 0〜1、初期値0.35 |

</details>

### 再利用・中断・復旧

| 目的 | 操作・注意 |
|---|---|
| Promptを修正して再生成 | 最終Promptを編集 →「編集したPromptで再生成」。保存済み解析を再利用 |
| 画像を生成せず成果物を作る | 「Prompt・ワークフローのみ作成」 |
| 停止 | 右上の「停止」。通信・前処理の終了待ちあり。再起動後の自動再開なし |
| ZIPのみ再試行 | 「ZIPを再作成」。個別成果物と既存の完成ZIPは保持 |
| 中断結果の回収 | 「中断した生成の確認・復旧」→ 対象を開く →「ComfyUIの状態を再確認」→ 完成済みなら「完成画像を取り込む」 |

参考画像・指示・追加Prompt・タグ設定・LoRA構成を変えた場合は再解析します。解析再利用と連続生成は併用できません。

タイムアウトでも受付済みの場合があるため、再操作の前に実行状態を確認します。回収は保存ID・ワークフローの一致を検証し、再投入・重複保存を避けます。途中保存した画像は保持し、連続生成分は未確定レビューへ戻します。回収時は生成画像のWD再解析を行いません。

<a id="batch"></a>
## 連続生成・条件比較

基準条件を設定 →「連続生成」を有効化 → 方式・範囲を指定して実行 → レビューで「残す」を選択 → 枚数を確認して確定します。

| 方式 | 条件 |
|---|---|
| 同時に変化 | 1〜20回。開始値から終了値へ指定項目を同時に変化 |
| 条件マトリクス | 最大2軸・各2点以上・積20枚以下。全組み合わせ |

対象はCFG・Steps・WDしきい値・各LoRAのMODEL / CLIP強度。シードは「全回共通」（既定）と「各回ランダム」から選べます。ランダム時はシード欄の値を使わず、各回の実際の値を履歴に保存します。「同時に変化」では数値項目を選ばず、シードだけ変える生成も可能です。条件比較には全回共通を推奨します。WDには参考画像とWD有効化、LoRAには対象選択が必要。Stepsは整数化後の重複不可です。

<a id="matrix"></a>
マトリクス例：CFG 3点 × LoRA強度2点 = 6条件。先頭項目が横軸、次が縦軸です。

**確定時は選択した画像・設定だけを通常ギャラリーへ保存し、未選択分と生成セットを削除します。0枚選択は全破棄です。** 途中停止・エラーでも完成済み画像は選別可能。未確定セットは自動削除対象外で、不要ならレビューから破棄します。セット名は80文字までです。

<a id="gallery"></a>
## ギャラリー

<a id="gallery-search"></a>
| 操作 | 仕様 |
|---|---|
| 検索 | 指示・最終Prompt・メモ・ラベル・モデル・LoRAの部分一致。ラベル指定は完全一致、期間は日本時間の生成開始日。複数条件はAND |
| 条件復元 | 「この設定を使う」。生成は開始しない。必要な参考画像は再選択 |
| 比較 | 「比較に追加」→「設定を比較」、2〜5枚。削除選択とは別 |
| お気に入り | 星を付ける。1枚で同じ実行全体を手動・自動削除から保護 |

<a id="annotations"></a>
「メモ・分類」で画像単位の注釈を保存します。メモ4000文字、ラベル各40文字・最大20個。連続生成では選別確定後に編集します。**メモ・ラベルは削除保護になりません。**

### 削除と保持

| 項目 | 仕様 |
|---|---|
| 手動削除 | 実行単位で全画像・Prompt・設定・注釈を削除。一括は最大500実行 |
| 自動削除 | 終了から既定10日。起動時と1時間ごとに確認 |
| 対象外 | お気に入りを含む実行、生成中、未確定セット、画像なしのPromptのみ実行 |
| 日数変更 | `gallery_retention_days`、`0`で無効。再起動で反映。[設定](CONFIGURATION.md) |

ComfyUIのoutput・ダウンロード済みコピーは削除しません。保持したい画像はお気に入りにし、別途バックアップします。

<a id="settings"></a>
## 設定の保存・再利用

| 保存単位 | 操作・内容 |
|---|---|
| 履歴 | ギャラリーの「この設定を使う」で実行条件を復元 |
| 設定プリセット | モデル・Prompt・LoRA・生成条件を保存 →「読み込む」。最大50件。画像・連続生成範囲は含まない |
| 指示文 | 「指示を新規保存」→「指示を読み込む」。最大100件、名前80文字・本文8000文字、同名不可。更新・削除は「保存した指示の管理」 |

<a id="recommendations"></a>
モデルは「現在の設定を推奨値として登録」、LoRAは管理画面の「推奨強度を保存」で登録し、「推奨値を適用」で反映します。選択・履歴復元では自動適用しません。名前・相対パス変更で別登録になります。

<a id="analysis-model"></a>
解析モデルはOllamaへ導入後、「システム管理 → アプリ設定」の `model` を保存して再起動します。複数解析先には同名モデルを用意。履歴復元はアプリ設定を変えず、新規解析には現在値を使います。変更後は再解析してください。

<a id="lora-folders"></a>
LoRAの許可フォルダーはアプリ設定でモデルごとに登録し、再起動。[対応ルール](CONFIGURATION.md#lora-folders) を参照してください。

<a id="lora-management"></a>
## LoRA管理

ComfyUIが認識するLoRAを選択し、情報を編集して保存します。

| 項目 | 保存・適用 |
|---|---|
| トリガーワード | 「保存」で登録。LoRA選択時に生成欄へ入力 |
| URL・メモ・管理用タグ | 参照・分類用。タグ各40文字・最大20個。Promptへ追加しない |
| 推奨プロンプト | 最大8000文字。生成欄の「推奨プロンプトをコピー」で利用。自動追加しない |
| 推奨MODEL / CLIP強度 | 「推奨強度を保存」で別保存。生成欄で明示的に適用 |
| サンプル画像 | 選択時に自動保存。PNG / JPEG / WebP、1枚5MB・最大6枚。生成用の参考画像には自動追加しない |

生成欄での編集は登録値を変えません。「登録を削除」はLoRA本体・サンプル・推奨強度・履歴を削除しません。サンプルは個別削除、強度は「推奨強度を解除」を使います。ComfyUIから消えても登録情報は残ります。

<a id="saved-data"></a>
## 保存先・バックアップ

`output_dir`（既定 `web-results`）に履歴・設定用SQLite、`lora-samples/`、実行ID別の画像・解析JSON・ワークフロー・Prompt・ZIPを保存します。LoRAの推奨プロンプトを含む登録情報は `lora-triggers.sqlite3` です。

**停止後に設定と出力先全体を同じ時点で保管**します。DBだけ・PNGだけでは全体を復元できません。ブラウザーの一時入力・参考画像、外部モデルは別管理です。[バックアップ・復旧](MAINTENANCE.md#backup)
